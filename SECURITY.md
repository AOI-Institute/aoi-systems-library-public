# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security problem.

Use GitHub's private vulnerability reporting: open the **Security** tab of this repository and choose
**Report a vulnerability**. You will get a response as soon as a maintainer can look at it.

## Scope and status

This library is an **unreleased collection of reference implementations** written to a shared spec
(auth, billing, webhooks, RBAC and similar SaaS building blocks) in eight languages. Many suites still
fail (see the status table in the README). **Do not run this code in production without your own review.**
Reports about weaknesses in the reference implementations are welcome and are treated as regular bugs
unless they affect this repository's tooling or CI, in which case please use the private route above.
